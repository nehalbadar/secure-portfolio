# Ethical Use & Safety

This project is a **training lab** for learning secure development and security testing practices.

## Rules
- Only test targets you **own** or have **explicit written permission** to test.
- Keep the lab **local-only** (default configuration binds to `127.0.0.1`).
- Do not publish credentials, session tokens, or sensitive data.
- If you write a walkthrough for your portfolio, focus on:
  - the *security concept*
  - how you *validated the issue*
  - the *fix/mitigation*
  - how you *verified the fix*

## Why this matters
Security tools and techniques can be misused. This lab is meant to build defensive skills and demonstrate responsible practice.

## If you ever deploy
Recommendation: avoid deploying intentionally vulnerable apps to the public internet.
Prefer a **recorded demo** (video) and a clean codebase showing mitigations.
