# Weather Forecast Dashboard

Minimal Weather Forecast Dashboard using Open-Meteo (no API key required) and a modern static frontend.

Requirements:
- Node.js 14+

Setup:

1. Install dependencies and run:

```bash
cd weather-app
npm install
npm start
```

2. Open http://localhost:5001

Notes:
- The server caches responses for 5 minutes.
- You can search by city or use the "Use my location" button.
- No API key required (uses Open-Meteo geocoding and forecast APIs).
